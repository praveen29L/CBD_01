Project Summary

Web application that allows authorized users to upload policy documents (PDF, DOCX, TXT), automatically summarizes them, and enables natural-language questions. It uses sentence embeddings and FAISS for semantic retrieval and a QA model for concise answers. Secure access is implemented using OTP authentication and user management via SQLite.

Use Case Employee self-service for HR / IT / Admin policies

Deliverables Document upload, summarization, semantic search, chatbot UI, OTP login.

Key Benefits
  • Faster retrieval of policy answers (semantic search vs keyword search)
  • Automatic summaries for long policy documents
  • Secure access with OTP-based verification
  • Easy integration for HR/IT teams

Technical Features

Document Ingestion

Supports PDF, DOCX and TXT upload with robust text extraction (PyPDF2, python-docx).

Summarization

Abstractive summarization using Transformer models (BART/T5) to provide concise overviews of long policies.

Semantic Search & QA

Sentence-BERT embeddings + FAISS for retrieval; extractive QA (RoBERTa SQuAD) to answer user queries from retrieved context.

Authentication

OTP-based verification (PyOTP) and user management with Flask-SQLAlchemy and SQLite.

Scalability

FAISS handles fast similarity search; model caching and optional persistence for production deployments.

UI

Bootstrap-based responsive site and floating chatbot widget for intuitive user interactions.
